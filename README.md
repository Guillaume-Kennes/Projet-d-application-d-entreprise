# Internship Management Application

This project is a full-stack application that simulates an internship management system designed in a context similar to a real enterprise environment.

It is structured using a 3-tier architecture with a Java backend, a JavaScript frontend, and a SQL database.

## Project Structure

- Backend: Java application handling business logic and data management
- Frontend: JavaScript web application providing the user interface
- Database: SQL-based persistence layer

## Requirements

- Java installed (for backend execution)
- Node.js and npm installed (for frontend execution)

## How to run the project

### Backend

Run the main class located at:
"src/main/java/be/vinci/pae/main/Main.java"

This will start the backend server.

By default, the backend runs on:
http://localhost:3000

### Frontend

In a terminal, navigate to the frontend directory:
webapp

Then install dependencies and start the application:
```bash
npm install
npm start
```

By default, the frontend runs on:
http://localhost:8080
  
## Notes

Ensure that the backend is running before starting the frontend to avoid connection issues.
